# Domain WHOIS and DNS Monitor

This project is a Python-based domain monitoring tool. It reads a list of domain names, runs WHOIS queries, extracts registration details with TLD-specific patterns, checks DNS/IP records and sends email alerts when a domain expiration date is close.

The original project data has been cleaned for GitHub. Real domain lists, generated WHOIS output, generated DNS output and personal email information were removed.

## Project Structure

```text
domain-whois-monitor/
├── domainsor.py            # Main WHOIS query script
├── dnssor.py               # DNS/IP lookup script
├── timesor.py              # Expiration-date email alert script
├── tld.py                  # Selects the correct TLD parser
├── uzanti.py               # TLD-specific WHOIS regex patterns
├── deneme.txt              # Input domain list
├── yaz.txt                 # Generated WHOIS output
├── trhyaz.txt              # Generated expiration-date output
├── ipwrite.txt             # Generated DNS/IP output
├── requirements.txt        # Python dependencies
├── .gitignore
└── README.md
```

## Requirements

The current code uses Python 2 syntax, so it should be run with Python 2.7 unless the code is migrated to Python 3.

The system must also have the `whois` command available.

Install Python dependencies:

```bash
pip install -r requirements.txt
```

## Data Files

### `deneme.txt`

This is the main input file for `domainsor.py`.

Put one domain or subdomain on each line:

```text
example.com
www.example.org
subdomain.example.net
```

The original domain list was removed before publishing. Only safe example domains are included.

### `yaz.txt`

This file is generated by `domainsor.py`.

It stores WHOIS results in this style:

```text
example.com
domain_name---> EXAMPLE.COM
registrar---> Example Registrar
expiration_date---> 2030-01-01T00:00:00Z
name_servers---> ['NS1.EXAMPLE.COM', 'NS2.EXAMPLE.COM']
```

Before committing to GitHub, remove real WHOIS output if it contains internal or private data.

### `trhyaz.txt`

This file is generated by `domainsor.py` and read by `timesor.py`.

It should contain a domain name, then its expiration date, then a blank line:

```text
example.com
2030-01-01T00:00:00Z

example.org
2031-Jan-15
```

The original expiration-date records were removed before publishing.

### `ipwrite.txt`

This file is generated by `dnssor.py`.

Expected line format:

```text
Domain: NS1.EXAMPLE.COM IP: 192.0.2.10
Domain: NS2.EXAMPLE.COM IP: 192.0.2.11
```

The original DNS/IP output was removed before publishing.

## Email Configuration

`timesor.py` contains three local email settings:

```python
gonderici_mail = ''
gonderici_sifre = ''
alicilar = []
```

These values were cleaned before publishing.

Fill them only on your own computer. Do not commit real email addresses, Gmail app passwords, API keys, tokens or other secrets to GitHub.

## Alert Flow

The main alert flow uses these files:

1. Add domains to `deneme.txt`.
2. Run `domainsor.py`.
3. `domainsor.py` writes full WHOIS output to `yaz.txt`.
4. `domainsor.py` writes expiration dates to `trhyaz.txt`.
5. Run `timesor.py`.
6. `timesor.py` reads `trhyaz.txt` and sends an email alert for domains whose expiration date is close.

In the current code, the alert threshold is 150 days.

## Usage

Run the main WHOIS scan:

```bash
python domainsor.py
```

Run DNS/IP lookup:

```bash
python dnssor.py
```

Run expiration-date email alert:

```bash
python timesor.py
```
